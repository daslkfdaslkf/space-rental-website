# 毛泽东语录检索站

## 项目简介

主题检索 + 原文展示型资料站。用户输入问题、困惑或关键词，系统先做主题匹配，再展示相关的毛泽东语录原文、出处和时间。

**核心定位**：不做个性化劝导，不把语录写成对用户的直接回答，仅做客观的主题-语录资料展示。

---

## 当前已完成功能

### 核心功能
- **主题检索**：输入问题或关键词 → 四层语义匹配 → 至少展示3条相关语录
- **主题浏览**：30个主题分类，每个主题可直接查看全部语录
- **语录详情**：点击卡片弹窗，展示全文、出处、时间、主题标签
- **一键复制**：弹窗内复制按钮，格式为"原文 —— 出处（时间）"
- **随机语录**：每次随机展示一条语录，带淡入动画
- **示例搜索标签**：快速填入示例词开始搜索

### 搜索智能化
1. **语义扩展层（SYNONYM_MAP）**：口语/网络词 → 标准意图词（如"被背刺" → "被诋毁、被出卖"）
2. **意图识别层（INTENT_MAP）**：精准映射30+类场景到主题分类（人际/职场/情绪优先级最高）
3. **打分排序层（scoreQuotes）**：主题命中、关键词命中、原文直接命中多维打分
4. **保底补充层**：不足3条时自动在同主题补充，完全无匹配时从逆境/乐观类兜底

### 数据库
- **语录总数**：129条
- **主题分类**：30个，全部对应语录数据，无缺失
- **涵盖主题**：共产党、阶级斗争、社会主义、人民内部矛盾、战争与和平、人民战争、人民军队、党的建设、思想教育、群众路线、调查研究、实事求是、自我批评、团结、纪律、艰苦奋斗、自力更生、青年、妇女、文化艺术、科学技术、教育、卫生、体育、战略战术、谦虚谨慎、学习、革命英雄主义、革命乐观主义、逆境奋斗

## 功能入口

| 路径 | 功能 |
|------|------|
| `index.html` | 主页（搜索、主题浏览、随机语录） |
| `index.html#search-section` | 直达搜索框 |
| `index.html#categories-section` | 直达主题分类列表 |
| `index.html#random-section` | 直达随机语录 |

---

## 文件结构

```
index.html              主页
css/style.css           样式文件（响应式，适配移动端和桌面端）
js/quotes-data.js       数据文件（QUOTES_DATA + CATEGORIES + INTENT_MAP + SYNONYM_MAP）
js/main.js              交互逻辑（搜索、渲染、弹窗、随机语录）
README.md               本文档
```

---

## 数据结构

### 语录字段（QUOTES_DATA）
```js
{
  id: number,
  quote: string,          // 语录原文
  source: string,         // 出处（书名/讲话/文章）
  date: string,           // 时间
  category_lv1: string,   // 一级主题（对应CATEGORIES.id）
  category_lv2: string,   // 二级主题
  tags: string[],         // 主题标签
  scenes: string[],       // 适用场景
  query_keywords: string[] // 搜索关键词
}
```

### 主题分类字段（CATEGORIES）
```js
{
  id: string,      // 主题ID，对应语录的category_lv1
  label: string,   // 显示名称
  icon: string,    // Emoji图标
  desc: string     // 简短描述
}
```
